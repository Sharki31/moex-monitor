# Монитор акций MOEX

Локальное веб-приложение для отслеживания всего рынка акций Московской биржи: цены, сигналы теханализа («покупать/продавать»), рейтинг рекомендаций и прогноз тренда по историческим данным.

## Запуск

Требуется Node.js 18+ (проверено на v22). Зависимости не нужны — используется встроенный `fetch`.

- Двойной клик по `start.bat`, или
- `node server.js`

### Деплой в облако (работает без включённого ПК)

1. Создай аккаунт на **github.com** и пустой публичный репозиторий (например `moex-monitor`).
2. Загрузи код в репозиторий (git push, либо «Add file → Upload files» через сайт).
3. Создай аккаунт на **render.com** (можно через Google) → **New + → Web Service** → подключи репозиторий → план Free → **Create Web Service** (настройки уже описаны в `render.yaml`, старт — `npm start`).
4. Через пару минут получишь адрес вида `https://имя.onrender.com` — открой его на телефоне и добавь на главный экран: HTTPS из коробки, push-уведомления о сигналах работают.

Ограничения бесплатного тарифа Render: после ~15 минут без посещений сервис «засыпает» — первое открытие занимает 30–60 секунд, дальше быстро. Папка `cache/` на хостинге временная: она пересоздаётся автоматически, ничего настраивать не нужно.

Затем открыть **http://127.0.0.1:3000** (на этом компьютере) или **http://IP-компьютера:3000** с телефона в той же Wi-Fi сети — адрес сервер печатает при старте (обычно `192.168.x.x`).

### Установка на телефон (PWA)
1. Телефон и компьютер — в одной Wi-Fi сети; сервер запущен.
2. Открой в браузере телефона адрес компьютера (например `http://192.168.0.103:3000`).
3. **Android (Chrome)**: меню ⋮ → «Добавить на главный экран» → появится иконка приложения.
4. **iPhone (Safari)**: «Поделиться» → «На экран „Домой“» — откроется как отдельное приложение без адресной строки.
5. Файлы интерфейса кэшируются: при временной потере сети приложение откроется, а данные подтянутся, когда связь вернётся.

### Уведомления о резких падениях
Кнопка **«Сигналы»** в шапке: сервер каждые 5 минут в торговое время проверяет весь рынок; бумага попадает в сигнал, если она упала на **5% и больше за день** при обороте от 10 млн ₽. Повторный сигнал по той же бумаге — не раньше чем через 3 часа либо если падение усугубилось ещё на 2 п.п. Список хранится 24 часа; клик по строке открывает анализ бумаги. Нажми «Включить уведомления», чтобы получать системные push при новых сигналах (клик по push открывает анализ тикера).

> Ограничение браузеров: системные уведомления требуют HTTPS (localhost — исключение). На компьютере через `127.0.0.1` они работают полностью; на телефоне по `http://192.168.x.x` пока работают только красный бейдж и панель «Сигналы» внутри приложения. Полноценный push на телефон добавим, когда поднимем HTTPS.

## Возможности

- **Обзор** — таблица всех акций режима TQBR: цена, изменение %, оборот, капитализация. Поиск, сортировка, автообновление каждые 60 секунд. Клик по строке — переход к анализу.
- **Анализ** — свечной график (lightweight-charts) с SMA 20/50/200 и полосами Bollinger; индикаторы RSI (14), MACD (12/26/9); список сигналов; итоговый вердикт по скорингу.
- **Рекомендации** — скан топ-N бумаг по обороту с оценкой каждой и сортировкой по скору.
- **Идеи** — упрощённые подсказки человеческим языком: топ-40 крупнейших компаний, для каждой «Хорошая точка входа» / «Можно купить понемногу» / «Держать» / «Подожди» / «Не покупать» с объяснением (RSI, отклонение от максимума года, скор, новостной фон). «Хорошая точка входа» даётся только когда падение остановилось (цена выше средней за 20 дней); резкое падение при негативных новостях понижает совет до «Подожди». Кнопка «В портфель →» переносит тикер в форму портфеля.
- **Портфель** — пассивная стратегия: позиции (кол-во, цена покупки, ожидаемый дивиденд ₽/год на акцию), стоимость, P/L ₽ и %, проекция годового дивидендного дохода и доходность портфеля, техсигнал по каждой позиции (подсказка «зона докупления» при RSI < 35). Обязательны только тикер и количество. Повторное добавление того же тикера не создаёт дубликат: количество суммируется, цена покупки усредняется по количеству. Портфель хранится только в браузере (localStorage).
- **Калькулятор пассивного дохода** (внутри «Портфеля») — вводишь желаемый доход ₽/мес и размер ежемесячных взносов; калькулятор учитывает текущий портфель (капитал и фактическую дивидендную доходность), показывает нужный капитал, сколько осталось накопить и через сколько лет цель будет достигнута — с учётом роста дивидендов, роста цен и инфляции (цель сравнивается в «сегодняшних деньгах»). Годовая таблица прогресса, настройки сохраняются в localStorage.
- **Прогноз** — лог-линейная регрессия по последним 120 торговым дням, горизонт 30 торговых дней, коридоры 68% и 95%.
- **Новости** — заголовки проверенных СМИ (Интерфакс, Коммерсантъ, Ведомости, ТАСС), грубая тональная оценка по ключевым словам (+/− счёт по упоминаниям компании). Показывается в «Анализе» и учитывается колонкой «Новости» в «Идеях».
- **Сигналы** — кнопка в шапке: список бумаг, упавших за день на 5% и больше («возможная срочная продажа»), с бейджем непрочитанных и браузерными уведомлениями.

### Скоринг сигналов

| Сигнал | Вес |
|---|---|
| Тренд вверх/вниз (цена и SMA20 по одну сторону, SMA20 vs SMA50) | ±2 |
| Золотой крест / мёртвый крест (SMA50 vs SMA200) | ±2 |
| RSI < 30 (перепроданность) / RSI > 70 (перекупленность) | ±2 |
| Пересечение MACD сигнальной линии вверх/вниз | ±1.5 |
| Цена у нижней/верхней границы Bollinger | ±1 |
| Итог | −8.5…+8.5 |

Вердикты: ≥ +4 сильная покупка, ≥ +2 покупка, −1.9…+1.9 держать, ≤ −2 продажа, ≤ −4 сильная продажа.

## API

| Endpoint | Описание |
|---|---|
| `GET /api/health` | Состояние сервера, открыт ли рынок (MSK 09:45–19:00) |
| `GET /api/securities` | Все бумаги TQBR с котировками (кэш 30 с в сессии / 10 мин вне) |
| `GET /api/candles?secid=SBER&days=365` | Дневные свечи (кэш 1 ч) |
| `GET /api/analysis?secid=SBER` | Индикаторы, сигналы, скор, вердикт, прогноз |
| `GET /api/scan?limit=50` | Скоринг топ-N бумаг по обороту (кэш свечей 30 мин) |
| `GET /api/ideas?limit=20` | Топ-40 по капитализации + простой совет (buy/small/hold/wait/avoid) + новостной фон |
| `GET /api/news?secid=SBER` | Свежие заголовки об эмитенте с тональной оценкой (кэш фида 10 мин) |
| `GET /api/alerts` | Сигналы «резкое падение» (≤ −5% за день, оборот ≥ 10 млн ₽, окно 24 ч) |

Капитализация считается на клиенте: `ISSUESIZE × цена` (число акций из ISS). Ожидаемые дивиденды в бесплатном ISS отсутствуют — вводятся пользователем вручную.

## Данные и ограничения

- Источник: официальный открытый **MOEX ISS API** (`iss.moex.com`), без ключей и регистрации.
- Бесплатные данные идут с задержкой до ~15 минут; таблица обновляется раз в 60 с.
- Дивиденды ISS **не отдаёт**: endpoint `/securities/<TICKER>/dividends.json` возвращает только описание бумаги (проверено 19.10.2026), поэтому дивиденд на акцию вводится вручную — его легко посмотреть на moex.com (страница бумаги, раздел «Дивиденды»).
- При недоступности MOEX сервер отдаёт данные из дискового кэша (папка `cache/`) с пометкой `stale`.
- Прогноз — статистическая экстраполяция, а не предсказание; R² показывает качество подгонки тренда.

## Безопасность

- Сервер слушает `0.0.0.0` — доступ с этого компьютера и устройств в **локальной сети** (домашний Wi-Fi). Приложение читает только публичные данные MOEX, паролей нет; портфель хранится в браузере каждого устройства.
- Только GET-запросы; тикер валидируется по шаблону; защита от path traversal.
- Исходящие запросы: `iss.moex.com` (котировки) и RSS перечисленных СМИ (новости).

```

├── lib/
│   ├── cache.js         Кэш память+диск с TTL

│   ├── analysis.js      SMA, EMA, RSI, MACD, Bollinger, скоринг
│   ├── news.js          RSS проверенных СМИ + тональность заголовков

├── scripts/
│   └── make-icons.js    Генерация PNG-иконок PWA (чистый Node, без зависимостей)
├── public/
│   ├── index.html       Интерфейс (5 табов + панель сигналов)
│   ├── app.js           Логика UI, графики, сигналы, уведомления
│   ├── style.css        Тёмная тема
│   ├── manifest.webmanifest  Манифест PWA (установка на телефон)
│   ├── sw.js            Service worker (офлайн-кэш статики)
│   ├── icon-192.png / icon-512.png  Иконки приложения
│   └── lightweight-charts.js  Библиотека графиков v4.2.3
├── start.bat            Запуск в один клик
└── cache/               Дисковый кэш (создаётся автоматически)
```

## Дисклеймер

Приложение носит информационный характер и **не является индивидуальной инвестиционной рекомендацией**. Используйте данные для личных целей.

Новостная оценка — грубая эвристика по ключевым словам в заголовках, а не ИИ-анализ: она может ошибаться, пропускает важные события и не видит фундаментальные показатели компаний. Источник дивидендов ищите на странице бумаги на moex.com (раздел «Дивиденды»).
